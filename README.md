# Phishing Awareness Training Pack

## Overview
This repository provides educational resources and reference guides to assist organizations in combating phishing attacks. It contains actionable checklists and guides to help non-technical staff spot deceptive communications and report them safely to the security operations team.

## Repository Contents
- `guide/employee-phishing-guide.md`: A non-technical manual detailing common email phishing vectors.
- `indicators/red-flags-checklist.md`: A quick reference checklist for identifying suspicious email headers, links, and attachments.
